# Code for my Bachelor's Thesis

**"Communication Interfaces for Distributed Augmented Reality Applications in Industrial Contexts"**

**Grade: 1.3 (Very Good)**

## Overview

This repository contains the source code developed for my Bachelor's thesis, focusing on **distributed augmented reality (AR) applications** within industrial contexts. The implementation includes a Python server for **manipulating glTF files**, enabling lightweight and efficient sharing of 3D volumes of interest over communication networks.

---

## Thesis Abstract

This thesis investigates the application of augmented reality (AR) technologies to **industrial environments** and presents a solution for **sharing 3D volumes of interest** across distributed computing and communication networks. The primary objective is to design and implement a system that transmits and receives 3D volumes in a compact, standardized **glTF format**, leveraging AR for improved collaboration and efficiency.

Key components of the project include:

- **Technical Framework**: An overview of Vuforia extended tracking, voxel carving, the Marching Cubes algorithm, and the glTF format.
- **Implementation Details**:
  - Voxel carving to model 3D shapes from volumetric data.
  - The Marching Cubes algorithm for creating 3D meshes.
  - Exporting and importing 3D objects in glTF format.
- **Evaluation**: A user study assessing system effectiveness and usability.  
  Results indicate promising usability, minimal deficiencies, and clear benefits for **industry professionals** working collaboratively and remotely on projects.

The project demonstrates potential applications in industries such as **healthcare, architecture, and engineering**, enhancing **productivity**, reducing costs, and opening avenues for **further research** into AR-enabled communication systems.

---

## Features

- **Distributed 3D Volume Sharing**: Lightweight transmission of 3D models using glTF.
- **Python-Based Server**: Handles .gltf file manipulation for efficient data exchange.
- **Voxel Carving & Mesh Generation**: Generates accurate 3D reconstructions using voxel carving and the Marching Cubes algorithm.
- **Integration with AR Technology**: Utilizes Vuforia for tracking and augmented visualization.
